# 维护命令

这些文件是浏览器控制台命令，不是 Tampermonkey 用户脚本，也不是终端命令。只读取当前页面，不修改页面、不刷新/加载结果、不发网络请求。

## 收集「计算不可得」

命令文件：[calculation-unavailable.js](calculation-unavailable.js)。

1. 在国际服或 QQ 的 trade2 装备搜索页启用装备防御排序脚本，加载结果，保留出现「计算不可得」的浮窗。
2. 打开本目录的 `calculation-unavailable.js`，复制文件全部内容。
3. 在交易页按 **F12 → Console（控制台）**，粘贴并按 Enter 执行。不要在本地文件页面或终端执行。
4. 控制台会输出格式化的 JSON 文本；复制完整数组（从 `[` 到 `]`）发给助手。Chromium 控制台可右键该输出选择「Copy string contents / 复制字符串内容」，也可手动复制。

输出包含所有出错装备的结果 ID、失败列和悬停原因、防御/品质/物品等级/词缀字段、字段是否位于原始属性行、增幅文字，以及孔结构。保留重复字段以便排查原始属性与插件摘要的冲突；不读取卖家账号、上架时间、手续费、装备名称或整条结果 HTML。

- 「未找到装备防御排序浮窗」：确认脚本已启用并刷新支持的交易页，再加载装备结果。
- 「当前浮窗没有『计算不可得』的装备」：命令未收集到失败行；不是计算修复证明。确认出错装备仍在当前浮窗。
- `sourceFound: false`：对应交易结果行已不存在，但浮窗仍保留该行；将输出一并发给助手。

命令使用局部作用域，可以重复执行；不会修改装备计算规则、排序或交易数据。发送前可自行检查 JSON 内容。

## 收集装备信息（计算数值有误）

命令文件：[equipment-info.js](equipment-info.js)。执行位置和复制方法同上：在交易页 **F12 → Console** 粘贴文件全部内容，按 Enter，再复制完整 JSON 数组发给助手。无需替换或重新安装主脚本。

- 默认收集当前浮窗的全部装备，包含可计算装备和「计算不可得」装备；不会加载更多结果。
- 输出包含每列显示值与悬停公式/原因、原始防御/品质/词缀、重复字段及嵌套词缀标记、装备属性行、部位、腐化/圣化状态证据与孔结构。不采集卖家账号、上架时间、手续费或整条结果 HTML。
- 只收集某件时，可在执行前把文件开头的 `const itemIds = [];` 改为 `const itemIds = ['结果 ID'];`；多个 ID 用逗号分隔。该设置仅过滤输出，不修改页面。留空表示全部。
- 发送数据时，请同时注明**哪件装备（结果 ID 或当前防御值）、哪列不对、你认为应是多少、依据或手算公式**。未知正确值时说明观察到的矛盾即可；不要先删掉相关词缀。
- 未匹配到装备会输出中文提示；`sourceFound: false` 表示源交易行已不存在，但保留浮窗数值用于排查。

验证：`node --check maintenance/equipment-info.js` 通过；非浏览器 DOM 冒烟覆盖可计算/失败装备、数值与公式、重复属性和嵌套词缀、增幅/部位/腐化/孔证据、ID 过滤、源行缺失、隐私字段排除、重复执行、DOM 不变及空列表/无面板提示。没有运行浏览器，实际交易页执行与输出仍需用户核对。

## 收集完整符文信息

命令文件：[rune-info.js](rune-info.js)。在交易页 **F12 → Console** 粘贴全部内容执行，将完整 JSON 数组发给助手。默认全部浮窗装备；可将开头 `const itemIds = [];` 改为 `const itemIds = ['结果 ID'];` 只收集指定装备。

输出保留每个孔的 HTML、图片 src/title/alt 等全部属性、所有 stat 字段（包括非 rune 类型的实际装备词缀）的 HTML/属性/嵌套标记、属性行、页面绑定提示及面板值/公式。不读取整条交易行或卖家信息；HTML/属性可能含页面插件额外数据，发送前可检查内容。

这是页面已渲染数据的完整采集，不是游戏后台数据查询。通用 `RuneSocketFilledSoul.png` / `RuneSocketFilledSpecial.png` 图标不能唯一识别具体符文，也不能证明绑定；页面没有符文名称或逐孔词缀映射时，命令无法补出这些信息。如果悬停某个孔会显示符文名称/属性，请另提供该提示截图或文字；命令不自动悬停、不请求后台接口。

已知「可骰出灵魂词缀」标记对应绑定镶嵌物 Medved's Tending，命定生命/魔力各 3%，见 [PoE2DB](https://poe2db.tw/us/Socket-bound_Augments)。该标记开启可骰词缀，不是额外防御属性；具体装备已骰出的属性需要看实际 stat 字段。

验证：语法检查与非浏览器 DOM 冒烟通过，覆盖孔图片属性、完整词缀 HTML、实际非 rune 词缀、嵌套标记、绑定提示、ID 筛选与页面不变。实际交易页执行、符文名称及逐孔映射是否存在仍待用户核对。

## 武器点伤列（v2.3.2）

- 武器模式为「DPS / 物理 / 元素 / 混沌 / 孔 / 价格」六列；护甲模式仍为五列。
- 物理、元素、混沌列显示当前武器面板各伤害区间的平均值之和，不乘每秒攻击次数；元素只包含火焰、冰冷和闪电。保留面板已有品质、词缀、符文效果，不反推裸基础。
- 总 DPS 算法保持不变：各类型平均点伤分别乘每秒攻击次数再求和。攻速缺失时总 DPS 不可得，但可解析的点伤仍显示；不存在的伤害类型为 0，无法解析的范围显示「计算不可得」。

## 总点伤列（v2.3.3）
