# poe-trade-tool

## 干什么的

用于 POE2 交易页的 Tampermonkey 用户脚本，在页面右侧显示可拖动的装备排序浮窗，比较护甲防御、武器伤害、可用孔数和标价。当前脚本版本：**v2.10.0**。

- 支持[国际服交易页](https://www.pathofexile.com/trade2)和[国服 QQ 交易页](https://poe.game.qq.com/trade2)。
- **护甲模式**：「总防御 / 护盾 / 闪避 / 护甲 / 保护 / 孔 / 价格」；可选显示性价比，开启「魔力换盾」后在保护右侧增加魔力列。
- **武器模式**：「总伤 / 物理 / 元素 / 混沌 / 孔 / 价格」；可选计算攻速、显示性价比和五类伤害明细。不再单列原始面板 DPS。
- 两种模式均有行内构成占比条、可选详细数值、按列排序和孔内增幅估算；已识别的腐化、圣化、复制状态显示为「腐 / 圣 / 复」。
- 只读取当前页面已加载的结果，不发网络请求、不自动加载或翻页、不修改交易数据。估算仅用于比较，不代表角色实际防御或技能伤害。

## 怎么安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 打开 Tampermonkey 管理面板，选择「添加新脚本」。
3. 删除编辑器中的模板内容，粘贴本仓库 [`poe2-equipment-calculator.user.js`](poe2-equipment-calculator.user.js) 的全部内容。
4. 按 `Ctrl+S` 保存，并确认脚本已启用。
5. 打开或刷新支持的 POE2 交易页，搜索装备并加载结果，点击页面右侧默认收起的「POE」圆形按钮展开浮窗。

更新脚本时，用最新文件的全部内容替换已安装脚本，保存后刷新交易页。

## 怎么使用

- **选择模式**：根据首件结果自动识别护甲或武器，也可手动切换；首件结果 ID 改变时恢复自动识别。护甲默认按总防御降序，武器默认按总伤降序。
- **切换排序**：点击列的表头排序，再次点击同一表头切换升降序。首次选择价格列为升序，其他列为降序；按未取整数值排序，同值保持原结果顺序，当前排序列不可计算的行置底。两种模式分别保留排序；关闭正在排序的性价比或魔力列时，回到该模式默认排序。
- **查看构成**：每件装备下方显示防御或五类伤害占比条；勾选「显示详细数值」显示正数项。护甲四类分项列始终显示，不受该开关影响。正常数值不提供计算公式悬停；「计算不可得」可悬停查看原因，孔数和占比条可悬停查看口径。
- **比较性价比**：勾选「显示性价比」，在总防御或总伤右侧显示该值除以标价金额，保留两位小数。价格排序和性价比均不换算货币；跨货币比较没有统一价值口径。
- **定位装备**：点击装备行或占比/详细行，页面滚动到对应交易结果；价格按钮保留键盘定位操作。选中文本时不跳转。悬停交易页装备会高亮浮窗对应行，不自动滚动。
- **回顶部 / 加载更多**：「回顶部」仅滚动交易页面；「定位加载更多」滚动并聚焦原生加载按钮，需你手动点击加载。未找到或按钮不可用时显示提示，不代点、不请求数据。
- **调整浮窗**：拖动标题栏或收起后的 POE 按钮移动；收起/展开按钮均为 48×48，切换保留右上角位置，越界时按视口钳制。拖动 POE 按钮后松开不展开；每次页面加载默认收起，不保存展开状态。
- **滚动与刷新**：展开宽度为 420px，窄窗口按视口缩小；仅列表区域滚动，操作栏留在列表外。结果变化后自动更新，也可点击「刷新」；刷新和加载更多保留当前排序。

## 计算与增幅口径

### 护甲

- 默认先移除已收录的孔内防御百分比增幅，保留装备自身词缀；品质不足 20% 补至 20%，更高品质保留。总防御是处理后护盾、闪避、护甲、保护之和，不是原面板防御，也不是移除所有装备词缀的裸基础值。
- 「高阶 / 完美」只选择估算档位，不再并排显示两档结果。默认不选增幅；勾选「防御百分比」后按可用孔减特殊孔估算，高阶每孔 18%、完美 20%，直接并入总防御、各分项和占比条。
- 「魔力换盾」按指定模型将 `非孔内最大魔力 + 2 × (非孔内智慧 + 全能力)` 以 **1 魔力 = 1 护盾** 计入总防御；护盾列仍是处理后的原生护盾，转换贡献单列为魔力。全能力只按其中的智慧折算，不乘三；不计孔内魔力/属性、Bonded、pseudo 汇总或角色/天赋魔力，也不对转换贡献应用品质和防御增幅。
- 开启「魔力换盾」后才能选择「魔力」增幅：高阶每孔 +40、完美 +50 最大魔力。仅加入所选档位估算，不叠加原有孔内魔力；与「防御百分比」互斥，也可都不选。关闭魔力换盾会取消已选的魔力增幅。
- 防御和魔力每孔数值乘装备的已识别镶嵌增幅效果倍率后向下取整；百分比按整数百分点取整。例如增加 60% 效果时，完美防御每孔 32%，完美魔力每孔 +80。
- **模型限制**：保护（Runic Ward）的品质与局部/全局百分比归类、魔力换盾均不是已验证的游戏机制。保护存在装备百分比归类疑义且需去除或追加孔内百分比时拒绝计算，不猜值。

### 武器

- 从装备伤害属性行读取区间平均，去除已识别的孔内局部物理百分比及物理/火/冰/电/混沌附加伤害，保留装备自身词缀。仅物理品质不足 20% 时补至 20%，元素与混沌不乘品质系数。
- 默认「总伤」为处理后的物理、元素、混沌平均单次伤害之和；勾选「计算攻速」后为该和乘每秒攻击次数，**仍使用处理后的伤害，不回退到原面板 DPS**。各分项列、五类明细与占比条始终不乘攻速。
- 增幅类型「物理百分比 / 电点 / 冰点 / 火点」最多选一项，可全部取消；按可用孔减特殊孔插满所选类型估算，结果直接并入对应伤害与总伤，不单独成列。

| 每孔增幅（未乘装备效果倍率） | 高阶 | 完美 |
| --- | --- | --- |
| 物理百分比 | 18% | 20% |
| 电点区间 | 1–30 | 1–40 |
| 冰点区间 | 9–15 | 16–20 |
| 火点区间 | 13–16 | 17–20 |

- 附加区间乘装备效果倍率后逐端向下取整再取平均，物理百分比按整数百分点取整；原有孔内局部伤害先移除，估算只加一次。档位数值使用攻击武器（Martial Weapon）口径，不采用 Wand/Staff 的法术效果；依据见 [PoE2DB Rune](https://poe2db.tw/us/Rune)。
- 明确的技能物理转化不影响武器面板反推；局部/作用域不明的物理转化、孔内词缀转化、无法确认倍率或缺失/冲突的局部增幅数据会拒绝计算。元素无法可靠分成火/冰/电时，不绘制部分占比冒充完整构成；总元素值仍可独立计算。
- 面板已经取整，反推是比较估算，不是精确还原游戏内部值；不含技能、暴击和角色加成。

### 孔数

- 孔列显示 **可用/总共**，按左侧可用孔排序。普通已填符文仍可替换；已识别的绑定孔扣除，珠宝转换孔的可用增幅孔为 0。缺少 stat 标记时不能证明隐藏的绑定状态，不从通用图片猜测符文。
- 实际 0 孔且未腐化/圣化时，按属性行类型假定补孔：胸甲、双手武器 2 孔；头盔、手套、鞋子、单手武器 1 孔。已有孔不补剩余孔，未知类型不猜；悬停注明假定补孔。
- **护甲假定补孔仅用于显示和孔排序，不参与防御或魔力增幅估算；武器选择增幅估算时使用显示的可用孔，包含假定补孔。** 未选武器增幅时，补孔不改变点伤或总伤。
- 「特殊孔」两种模式分别设置，范围 0–9、默认 0；估算孔数为 `max(0, 可用孔 − 特殊孔)`。仅预留位置，不猜测特殊符文数值。

## 问题诊断

在出错的交易页 **F12 → Console** 粘贴对应文件的全部内容执行，复制完整 JSON，并说明结果 ID、哪列不对、期望值或观察到的矛盾。无需在终端执行，也不会加载更多结果。

- 出现「计算不可得」：[calculation-unavailable.js](maintenance/calculation-unavailable.js)。
- 可计算但数值有误：[equipment-info.js](maintenance/equipment-info.js)。
- 需要完整符文与孔证据：[rune-info.js](maintenance/rune-info.js)；页面未渲染的信息无法补出，发送前检查 HTML/属性中可能包含的插件数据。
- 执行方式、输出说明和旧版本记录见[维护文档](maintenance/README.md)。旧版本列名和公式不代表当前版本。
