# poe-trade-tool

## 干什么的

用于 POE2 交易页的 Tampermonkey 用户脚本，在页面右侧显示装备防御排序浮窗，方便比较装备防御、孔数和价格。

- 支持[国际服交易页](https://www.pathofexile.com/trade2)和[国服 QQ 交易页](https://poe.game.qq.com/trade2)。
- 显示「当前防御 / 基础防御 / 高阶/完美 / 孔 / 价格」五列，支持点击表头排序。
- 武器模式显示「DPS / 总点伤 / 物理 / 元素 / 混沌 / 孔 / 价格」；各点伤移除已识别的孔内局部伤害增幅，保留装备词缀。仅物理品质不足 20% 补至 20%，更高品质保留；元素和混沌不受品质影响。DPS 仍使用原始武器面板伤害与攻速，因此不一定等于处理后的总点伤乘攻速。悬停查看反推与补品质公式；转化词缀、增幅效果倍率或缺失/无法解析的数据会显示「计算不可得」及原因。
- 只读取当前页面已加载的结果，不自动加载或翻页，不修改交易数据。

## 怎么安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 打开 Tampermonkey 管理面板，选择「添加新脚本」。
3. 删除编辑器中的模板内容，粘贴本仓库 [`poe2-equipment-calculator.user.js`](poe2-equipment-calculator.user.js) 的全部内容。
4. 按 `Ctrl+S` 保存，并确认脚本已启用。
5. 打开或刷新支持的 POE2 交易页，搜索装备并加载结果，页面右侧会出现浮窗。

更新脚本时，用最新文件的全部内容替换已安装脚本，保存后刷新交易页。

## 怎么使用

- **查看装备**：加载搜索结果后，浮窗默认按「高阶/完美」左侧的高阶防御降序排列；尚无结果时显示「尚未找到装备」。
- **切换排序**：点击任意列的表头选择排序，再次点击同一表头切换升序或降序。「高阶/完美」按左侧高阶数值排序；价格仅按金额排序，不换算货币。
- **查看说明**：将鼠标悬停在防御数值或孔数上查看详细说明。「高阶/完美」左侧是高阶结果，右侧是完美结果；显示「计算不可得」时，悬停查看原因。
- **定位装备**：点击价格，页面会滚动到对应的交易结果。
- **定位加载更多**：点击浮窗中的「定位加载更多」，页面会滚动并聚焦原生加载按钮，再由你手动点击加载。脚本不会代点或发出加载请求；未找到按钮或按钮暂不可用时会显示提示，新结果加载后浮窗自动更新。
- **调整浮窗**：拖动标题栏或收起后的 POE 按钮移动位置，点击「收起 / 展开」切换显示。两个按钮同为 48×48，切换保留右上角位置；展开空间不足时才按视口边界调整。
- **刷新列表**：结果变化后会自动更新，也可以点击「刷新」；刷新和加载更多结果会保留当前排序。
